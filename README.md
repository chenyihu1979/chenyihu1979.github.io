# 陈聚灏学习中心

This public GitHub Pages site is the cross-subject entry point for the learning materials.

- `index.html` — cross-subject home page
- `chemistry/index.html` — junior-high chemistry knowledge map with published/planned status
- `chemistry/knowledge-map.js` — chemistry roadmap data used by the map
- `chemistry/KNOWLEDGE_MAP.md` — readable inventory generated from roadmap data
- `chemistry/cb02/index.html` — published CB02 element navigation center
- `english/index.html` — English self-study Units 1–6
- `./chen-juhao-junior-math-lab/` — existing mathematics laboratory hosted in its own Pages repository
- `docs/LEARNING_LAB_STANDARD.md` — shared teaching and publishing contract for future modules
- `tools/audit_site.py` — local link and asset preflight (browser interaction still needs verification)

The home page offers two separate on-device learner choices and remembers only the last opened subject. It does not infer mastery or synchronize progress between devices.
