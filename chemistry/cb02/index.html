符号为什么这样写？

先找规律，再记特殊。 很多符号可以从英文名称直接看出来；Na、K、Fe 等“对不上”的，不是乱写，而是来自历史上的拉丁名称。

最容易看错的符号

C = 碳
只有一个字母 C
Ca = 钙
C 大写，a 小写
Cu = 铜
C 大写，u 小写
Cl = 氯
第二个是小写字母 l，不是大写 I
N = 氮
Na 才是钠
Na = 钠
第一个字母大写，第二个小写
规律：元素符号如果有两个字母，通常是“第一个大写，第二个小写”。例如 Ca、Cl、Na、Fe。
