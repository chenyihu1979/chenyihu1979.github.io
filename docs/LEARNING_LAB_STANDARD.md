# 家庭学习实验室：知识点开发约定

适用于陈聚灏、陈聚垚的跨学科网页实验室。用个人 skill `build-junior-learning-lab` 时，只需输入“学科 + 知识点”；此文档让普通仓库开发也能继承同一最低约定。

## 教学合同

每个新模块先写：知识点与先修、一个常见误解、可操作对象、操作后可观察变化、三步任务、错因与补弱提示、结束条件。学生流程是“小步进入→可视理解→动手操作→即时反馈→自动补弱→短时结束”。首屏提供明确的第一步，参数旁解释会产生什么效果；挑战和中考题放在理解之后。

## 学科补充

- 数学：图形、数值、公式和结论同步；点遵守曲线约束，模式互斥；导读按阶段变化，四区字体独立，分隔线可拖，首次 Fit 一次且不改数学参数。新模块以 F01-02 的实际正式页面与当前知识地图为参考。
- 化学：首次出现陌生化学式时解释中文名、符号、必须懂与暂不用懂；配平保持原子守恒，区分系数与下标；实验可重置。图片须真实且来源和授权明确。
- 英语：教材句子原样逐句呈现；每句有可用时的朗读、关键词 UK/US IPA 和中文、译文，仅难词给例句。不给没有依据的教材原句。

## 工程与发布

主站为此仓库 `index.html`；数学总览 `math/`，化学 `chemistry/`，英语 `english/`。化学地图数据在 `chemistry/knowledge-map.js`，修改后运行 `node chemistry/generate_map.cjs` 同步可读清单。新模块使用相对链接从学科总览进入，能返回；正式入口在 HTTPS 静态托管运行，不依赖开发端口。知识地图和总览要与实际发布文件同步。先运行 `python3 tools/audit_site.py .`，再在正式页面逐项操作验收按钮、导读、触控、窄屏、边界、导航和刷新。预检通过不等于交互通过。

## 本机学习记录

首页可选陈聚灏或陈聚垚，分别记录上次打开的**学科入口**；未选择时不记录。键名为 `learning-lab:v1:<learner>:last-subject`。此记录不是掌握度或具体知识点进度，也不跨设备同步。未来模块应在同一学习者命名空间中记录具体作答证据、提示次数和错因，再生成可解释的补弱建议；不要上传孩子的作答数据到公开仓库或统计服务。
